# summary

Get a CMS channel.

# description

Retrieves a channel by its identifier.

# examples

- Get a channel:

  <%= config.bin %> <%= command.id %> --target-org my-org --channel-id 0ap...

# flags.target-org.summary

Username or alias of the target Salesforce org.

# flags.api-version.summary

Salesforce API version used for CMS requests.

# flags.channel-id.summary

CMS channel identifier.
