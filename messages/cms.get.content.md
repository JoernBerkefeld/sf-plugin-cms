# summary

Get CMS content.

# description

Retrieves content by its key or identifier.

# examples

- Get content:

  <%= config.bin %> <%= command.id %> --target-org my-org --content-key-or-id news-banner

# flags.target-org.summary

Username or alias of the target Salesforce org.

# flags.api-version.summary

Salesforce API version used for CMS requests.

# flags.content-key-or-id.summary

CMS content key or identifier.

# flags.content-version.summary

Content version selector.

# flags.language.summary

Content language selector.

# flags.variant-version.summary

Variant version selector.

# flags.version.summary

Document version selector.
