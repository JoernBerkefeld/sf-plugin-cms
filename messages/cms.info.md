# summary

Show offline CMS contract and capability information.

# description

Reports the current public command inventory, result contracts, operation-specific support, and tested API baseline without contacting an org. Portable Email/Email Template deploy, API-led binary Image deploy and loose-image upload remain unqualified. Bounded UTF-8 text/plain Document retrieval, CREATE, bytes-only UPDATE and exact unchanged are unqualified; bounded two-org development-artifact acceptance covers the tested text/plain profile. Document UPDATE preserves metadata, native filename, MIME, language and type and never falls back to Image transport. Retained family registry declarations are labelled internal-engine-only: they do not advertise public retrieve/deploy availability. Authoring-baseline and sibling-aware update safeguards are not integrated into deploy.
