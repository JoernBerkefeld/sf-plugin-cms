# summary

Get a CMS content variant.

# description

Retrieves a content variant by its identifier.

# examples

- Get a variant:

  <%= config.bin %> <%= command.id %> --target-org my-org --variant-id 0aV...

# flags.target-org.summary

Username or alias of the target Salesforce org.

# flags.api-version.summary

Salesforce API version used for CMS requests.

# flags.variant-id.summary

CMS content variant identifier.
